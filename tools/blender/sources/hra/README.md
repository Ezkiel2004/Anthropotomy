# Human Reference Atlas female reproductive organs

Source files for the female reproductive layer (`system_model/layers/reproductive-female.glb`), which
`tools/blender/export_female_reproductive.py` fits into the Z-Anatomy pelvis. Z-Anatomy has no female
reproductive organs.

| File | NIH 3D entry | Contents |
|---|---|---|
| `VH_F_Uterus.glb` | [Uterus, Female (3DPX-020996)](https://3d.nih.gov/entries/3DPX-020996) | Body, fundus, cornua, anterior and posterior walls, lower uterine segment, cervix, internal and external os, abdominal ostia of the uterine tubes |
| `VH_F_Ovary_L.glb` | [Ovary, Female, Left (3DPX-020979)](https://3d.nih.gov/entries/3DPX-020979) | Left ovary |
| `VH_F_Ovary_R.glb` | [Ovary, Female, Right (3DPX-020980)](https://3d.nih.gov/entries/3DPX-020980) | Right ovary |

Credit: Human Reference Atlas 3D Reference Object Library (HuBMAP), built from the Visible Human female
data of the U.S. National Library of Medicine, published on NIH 3D. Licensed under
[Creative Commons Attribution 4.0](https://creativecommons.org/licenses/by/4.0/). The files here are
unmodified downloads (October 2026). The exported layer repositions them (the uterus is shown in the usual
anteverted position), renames the parts and recolours them in the viewer.

Models are for education, not for medical diagnosis or treatment. Use of NIH names or logos to suggest
endorsement is not permitted.
